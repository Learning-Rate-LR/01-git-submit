# 我的 GitHub 学习笔记

## 第一次 GitHub 小组实验总结

1. Repository（仓库）的作用是：存放代码、文档等文件的地方，包含 Git 版本历史。它分为公开（Public）和私有（Private），本次作业要求建立公开仓库。

2. Organization（组织）的作用是：代表一个团队或小组，作为仓库的所有者。它解决了个人账号归属问题，方便统一管理小组成员和权限。本次作业要求仓库所有者必须是 Organization。

3. Branch（分支）的作用是：在独立的分支上修改代码，不直接影响主分支（main/master）。组员可以在各自的分支上写作业，完成后发起合并请求。

4. Pull Request（PR）的作用是：请求将自己的分支代码合并到目标分支。它是团队协作的核心，方便组员之间互相审查代码，也便于老师核查贡献记录。

5. Issue 的作用是：用来跟踪任务、记录 Bug、发起讨论。本次作业中，如果需要更正仓库地址，就需要去指定的 Issue 页面选择 `00-group` 标签进行登记。

6. Public 和 Private 的区别是：Public（公开）仓库任何人都能直接访问 URL 看到内容；Private（私有）仓库只有授权的成员才能访问。本次作业要求必须是 Public，确保老师核查时链接直接有效。

7. commit 与 push 的区别是：commit 只提交到本地仓库，仅生成本地版本；push 将本地仓库的提交记录上传到远程仓库（比如 GitHub），同步到远端服务器，让同组其他人可以看到你的提交。
