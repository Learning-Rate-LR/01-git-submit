#我的Git学习笔记

## 第一次 Git 实验总结

1. **git add 的作用**
   将指定文件当前的修改放入暂存区，准备纳入下一次提交。它不会自动生成提交，也不会把文件上传到 GitHub。如果暂存后继续修改文件，需要再次执行 git add，才能将后续修改一起提交。

2. **git commit 的作用**
   将暂存区中的内容记录为本地仓库的一次提交，保存项目的版本快照和提交说明。可以通过 git log 查看提交历史。本地实验中使用“建立笔记和学习计划”作为提交说明，记录 notes.md 和 plan.md。

3. **git restore notes.md 的作用**
   默认使用暂存区中的内容恢复工作区的 notes.md，放弃该文件尚未暂存的修改。在课件的练习场景中，提交文件后追加一句练习文字，尚未执行 git add 时运行该命令，就会撤销这句文字。它不会删除已有的提交记录。类似地，已跟踪的 plan.md 在工作区误删且尚未暂存删除时，可以通过 git restore plan.md 恢复。

4. **commit 与 push 的区别**
   commit 把暂存内容记录到本地仓库，可以离线完成；push 将本地提交推送到远程仓库，需要网络和写入权限。本次作业使用已有的 Jiaqi-Tang 分支，提交个人总结后推送到远程同名分支，再通过 Pull Request 请求合并到 main。
