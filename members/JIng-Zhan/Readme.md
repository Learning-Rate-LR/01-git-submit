# 我的 Git 学习笔记

## 第一次 Git 实验总结

1. `git add` 的作用是：把工作区里的改动（新增、修改、删除）放入暂存区，表示这些内容将进入下一次提交。
2. `git commit` 的作用是：把暂存区中的内容写入本地仓库，生成一条提交记录，作为可以追溯和回退的版本节点。
3. 本次实验中 `git restore notes.md` 的作用是：放弃 `notes.md` 在工作区中尚未提交的修改，把它还原到最近一次提交后的版本。
4. `commit` 与 `push` 的区别是：`commit` 只把改动保存到本地仓库；`push` 才会把本地提交同步到 GitHub 远程仓库，其他人才能看到或合并。
